A list is a collection of elements in which each value is determined by an index. Their operations are as follows:
1. Data appending:
	1. Adding to the end: $\mathbb{O}(n)$ 
	2. Adding to the start: $\mathbb{O}(n)$ 
	3. Adding arbitrarily: $\mathbb{O}(n)$ 
2. Data removal:
	1. Removing to the end: $\mathbb{O}(n)$ 
	2. Removing to the start: $\mathbb{O}(n)$ 
	3. Removing arbitrarily: $\mathbb{O}(n)$ 
3. Data manipulation:
	1. Get a value: $\mathbb{O}(1)$ 
	2. Modify a value: $\mathbb{O}(1)$ 
	3. Search a value: $\mathbb{O}(n)$
