- Step 1: Select an element functioning as a pivot
- Step 2: Divide the list, placing elements to the left of the pivot and elements to the right apart.

Example:
- $L = [7,3,5,2,6,4,8,1]$
- $L = [3,5,2,6,4,1], 7, [8]$
- $L = [2,1], 3, [5,6,4], 7, [8]$
- ...
