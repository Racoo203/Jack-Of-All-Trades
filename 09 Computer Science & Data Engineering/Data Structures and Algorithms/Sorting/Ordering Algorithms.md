Definition: Given a function $g(n)$, we define $$\mathbb{O}(g(n))=\{f(n)\vert \exists n_0,C s.t. \vert f(n)\vert \leq C \vert g(n)\vert \text{ if } n > n_0 \}$$We say that $g(n)$ is of class $\mathbb{O}(g(n))$.
