# Jack-Of-All-Trades

A jack of all trades is a master of none, but oftentimes better than a master of one. Obsidian vault of all my collected knowledge from mathematics, data science, finance and more.

## Structure

Notes are organized by **subject domain**, not by degree — a concept only gets one note even if it first showed up in a BSc course and again, more rigorously, in an MSc course. Each note's frontmatter records `level` (BSc/MSc), `course`, `domain`, and a `status` (`empty` → `seeding` → `drafted` → `reviewed`).

- `00 Map of Concepts/` — one MOC per course: narrative, concept map, exam focus, open questions. Start here.
- `01`–`09` — domain folders (Mathematical Foundations, Probability & Statistics, Stochastic Processes, Optimization & Control, Dynamic Programming & RL, Machine Learning & AI, Finance & Markets, Cybersecurity, Computer Science & Data Engineering).
- `Resources/` — inbox for slides/homework/PDFs (mirrors the domain folders), used to ground note content. Entirely gitignored except its README: it holds copyrighted course material, past papers and solutions, and graded work, none of which belongs in a public repo.

See the vault strategy note (in the Claude project) for current status and the plan for filling in the remaining stub notes.
