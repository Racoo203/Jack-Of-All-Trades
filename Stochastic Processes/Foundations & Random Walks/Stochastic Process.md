## Definition
For a given [[Probability Space|probability space]] $(\Omega, \mathcal{F}, P)$ and a [[Measurable Space|measurable space]] $(S, \Sigma)$, a stochastic process is a collection indexed by some set $T$ of $S$-valued [[Random Variable|random variables]], written as:
$$
\{X_t : t \in T\}
$$
Where $\Omega$ is a sample space, $\mathcal{F}$ is a $\sigma$-algebra, and $P$ is a probability measure. Additionally, $S$ is a space measurable with respect to some $\sigma$-algebra $\Sigma$. Finally, $X_t$ is a random variable observed at time $t$.
