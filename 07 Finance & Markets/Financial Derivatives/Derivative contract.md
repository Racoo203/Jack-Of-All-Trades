## Definition
A **derivative security** (or **contingent claim**) is a financial contract whose value at expiration time $T$ is determined by the price of some underlying financial asset at time $T$. That is, a derivative's value depends on the value of more basic underlying variables (a stock, bond, currency, commodity, or index). A stock option, for example, is a derivative whose value depends on the price of the stock.

## Properties
### Taxonomy
Basic derivative types covered in this course: [[Forward contract]], [[Future contract]], [[Call option]], [[Put option]] (together forming [[European Options]] and [[American Options]]), and [[Swap contract]]. Unless stated otherwise, the underlying asset is assumed to pay no dividend for simplicity — dividends can be incorporated afterward (see [[Garman-Kohlhagen Formula]]).

### Pricing philosophy
Every derivative in this course is priced using the same two ideas: **[[No-arbitrage principle|no-arbitrage]]** and **[[Replicating Portfolio|replication]]** — find a portfolio of the underlying and a risk-free asset whose value exactly matches the derivative's payoff, and the derivative must be worth the same as that portfolio today (else an arbitrage opportunity exists).
